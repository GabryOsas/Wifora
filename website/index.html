Features

Built like studio gear, easy as an app.

Every component is engineered for minimum latency and reliability on real-world Wi-Fi.

Zero apps required

Scan the QR code or type the 8-character room code: Safari iOS and Chrome Android start listening instantly.

Ultra-low latency

35–65 ms end-to-end on Wi-Fi 5/6: perfectly in sync for movies, gaming, YouTube and monitoring.

Studio-grade quality

Fullband Opus 48 kHz stereo, up to 384 kbps with the Hi-Fi profile, always-on FEC against dropouts.

ANAE adaptive engine

Real-time RTT/jitter/loss telemetry with anti-flapping hysteresis: bitrate always optimal between 96–256 kbps.

Studio DSP chain

20 Hz sub-rumble high-pass, dialogue presence booster and a transparent −0.5 dBFS peak limiter.

Elastic playout

AudioWorklet buffer with micro-rate correction and hold-and-fade: network gaps become micro-fades, not clicks.

Installable PWA

Add Wifora to your home screen: offline-first service worker and an installable shell like a real app.

Secure by design

DTLS-SRTP encrypted media, timing-safe 256-bit host keys, per-IP rate limiting, strict CSP.

mDNS discovery

Your PC announces itself on the network as _wifora._tcp.local; the QR code remains the most reliable path.

How it works

From the Windows mixer to your ears in five steps.

1 · Capture
System audio capture
Chromium loopback on Windows, or the optional native WASAPI helper.
▼
2 · DSP
Web Audio mastering
20 Hz high-pass + Presence EQ + −0.5 dBFS peak limiter.
▼
3 · Encode
Opus 48 kHz
20 ms framing, always-on in-band FEC, DTX disabled.
▼
4 · Transport
P2P WebRTC on the LAN
Mandatory DTLS-SRTP, empty iceServers: nothing leaves the network.
▼
5 · Playout
Elastic playback
Adaptive 22–65 ms jitter buffer + drift-corrected worklet.

Download

Free, open source, ready in 60 seconds.

1 Requirements

  • Host PC: Windows 10/11 with Chrome or Edge
  • Node.js v18+ (nodejs.org)
  • Receivers: any modern browser on the same Wi-Fi

No virtual drivers, no audio cables, no network configuration.

2 Install & launch

git clone https://github.com/GabryOsas/Wifora.git
cd Wifora
npm install
npm start

On Windows you can also double-click Avvia-Wifora.bat or use the interactive menu via npm run menu.

3 Broadcast

  • Open http://localhost:3975 in Chrome/Edge
  • Click Start Audio Broadcast, pick Entire Screen and tick "Share system audio"
  • Scan the QR code with your phone: audio starts instantly
