Funzioni

Costruito come uno strumento da studio, usabile come una app.

Ogni componente è progettato per la latenza minima e per l'affidabilità sulle reti Wi-Fi reali.

Zero app richieste

Scansiona il QR code o digita il codice stanza di 8 caratteri: Safari iOS e Chrome Android entrano subito in ascolto.

Ultra-low latency

35–65 ms end-to-end su Wi-Fi 5/6: perfettamente sincronizzato per film, gaming, YouTube e monitoraggio.

Qualità da studio

Opus 48 kHz stereo fullband, fino a 384 kbps con il profilo Hi-Fi, FEC sempre attiva contro i dropout.

Motore adattivo ANAE

Telemetria RTT/jitter/packet loss in tempo reale con isteresi anti-flapping: bitrate 96–256 kbps sempre ottimale.

DSP chain da studio

High-pass 20 Hz contro il sub-rumble, presence booster sui dialoghi e limiter trasparente a −0.5 dBFS.

Playout elastico

Buffer AudioWorklet con correzione micro-rate e hold-and-fade: i buchi di rete diventano micro-fade, non click.

PWA installabile

Aggiungi Wifora alla home screen: service worker offline-first e shell installabile come una vera app.

Sicuro by design

Media crittografati DTLS-SRTP, chiavi host a 256 bit verificate in constant-time, rate limiting per IP, CSP rigorosa.

Discovery mDNS

Il PC si annuncia sulla rete come _wifora._tcp.local; il QR code resta il percorso più affidabile.

Come funziona

Dal mixer di Windows alle tue orecchie in cinque passaggi.

1 · Capture
Cattura audio di sistema
Loopback Chromium su Windows oppure helper WASAPI nativo opzionale.
▼
2 · DSP
Mastering Web Audio
High-pass 20 Hz + Presence EQ + Peak limiter −0.5 dBFS.
▼
3 · Encode
Opus 48 kHz
Framing 20 ms, FEC in-band sempre attiva, DTX disabilitata.
▼
4 · Transport
WebRTC P2P sulla LAN
DTLS-SRTP obbligatorio, iceServers vuoti: nulla esce dalla rete.
▼
5 · Playout
Riproduzione elastica
Jitter buffer adattivo 22–65 ms + worklet con correzione drift.

Download

Gratis, open source, pronto in 60 secondi.

1 Requisiti

  • PC host: Windows 10/11 con Chrome o Edge
  • Node.js v18 o superiore (nodejs.org)
  • Riceventi: qualsiasi browser moderno sulla stessa rete Wi-Fi

Nessun driver virtuale, nessun cavo audio, nessuna configurazione di rete.

2 Installa e avvia

git clone https://github.com/GabryOsas/Wifora.git
cd Wifora
npm install
npm start

Su Windows puoi anche doppio-cliccare Avvia-Wifora.bat oppure usare il menu interattivo con npm run menu.

3 Trasmetti

  • Apri http://localhost:3975 su Chrome/Edge
  • Premi Avvia Trasmissione Audio, scegli l'intero schermo e spunta "Condividi audio di sistema"
  • Scansiona il QR code col telefono: l'audio parte all'istante
