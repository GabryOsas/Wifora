Menu CLI & Script Windows

Il terminale di Wifora: un menu interattivo con dashboard live e tre script .bat per l'uso quotidiano senza righe di comando.

Menu interattivo

npm run menu
# oppure doppio clic su Avvia-Wifora.bat

Navigazione con ↑/↓ + Invio; q o Ctrl+C escono. Banner ASCII colorato incluso.

Voce Cosa fa
Start Wifora Server Garantisce che il Control daemon sia attivo, poi avvia lo streamer sulla porta scelta. Mostra gli indirizzi (localhost + LAN) e apre la dashboard live: log e ascoltatori aggiornati ogni 1.2 s.
Scorciatoie dashboard B riapre la pagina host nel browser · C apre il Control Center web · S ferma il server e torna al menu · Q ferma tutto ed esce.
Open Web Control Center Apre http://localhost:3976 nel browser (guida).
Change Port Chiede una nuova porta valida 1024–65535, la salva in wifora.config.json e riapplica al server se attivo.
View Network Adapters Elenca adapter fisici con IP; il primo è marcato "consigliato per iPhone"; per ognuno mostra il link diretto listen.html.
Stop Server & Free Port Stop grazioso via daemon; in fallback chiude i processi marcati Wifora e libera la porta (verifica finale inclusa).
Exit Program Ferma il server ed esce pulito.

Direct mode: se il Control daemon non risponde, il menu gestisce lo streamer direttamente (spawn marcato --wifora-managed) così non resti mai bloccato.

I tre file .bat

Avvia-Wifora.bat — avvio completo

  1. Imposta UTF-8 nella console (chcp 65001).
  2. Verifica che Node.js sia installato; altrimenti messaggio chiaro + link a nodejs.org.
  3. Se manca node_modules, esegue automaticamente npm install.
  4. Lancia il menu interattivo.

Controllo-Wifora.bat — console web

Stessi controlli d'ambiente, poi avvia il Control Center con apertura automatica del browser (control-center.mjs --wifora-control --open).

Termina-Wifora.bat — stop totale

  1. Trova i processi node.exe marcati --wifora-managed / --wifora-control e li termina forzatamente.
  2. Libera le porte 3975 e 3976 chiudendo eventuali proprietari rimasti.
  3. Riverifica lo stato Listen delle due porte e stampa [OK] Verified: ports 3975 and 3976 are free. oppure elenca quelle ancora occupate.

È anche lo strumento giusto per una disinstallazione pulita o quando un'istanza orfana tiene occupata una porta.
