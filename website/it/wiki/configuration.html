Variabili d'Ambiente & Configurazione

Tutte le leve di configurazione: variabili d'ambiente, file locale, costanti interne e modalità HTTPS.

Variabili d'ambiente

Variabile Default Descrizione
PORT 3975 Porta del server HTTP/WebSocket di streaming.
WIFORA_MAX_LISTENERS 5 Massimo ascoltatori per stanza. Valori fuori range limitati a 1–32.
LOG_LEVEL INFO DEBUG | INFO | WARN | ERROR | SILENT oppure numero 0–4. Valore invalido → INFO.
WIFORA_TLS_CERT — Percorso del certificato PEM (insieme a WIFORA_TLS_KEY attiva HTTPS/WSS).
WIFORA_TLS_KEY — Percorso della chiave privata PEM.
WIFORA_CONTROL_PORT 3976 Porta del daemon Control Center (solo loopback).
WIFORA_WASAPI_HELPER — Percorso esplicito di wifora-audio.exe.

Esempi

# PowerShell
$env:PORT = "8080"; $env:WIFORA_MAX_LISTENERS = "8"; npm start

# CMD
set PORT=8080 && set WIFORA_MAX_LISTENERS=8 && npm start

# bash / macOS / Linux
PORT=8080 LOG_LEVEL=DEBUG npm start

wifora.config.json

Il menu CLI e il Control Center condividono la porta scelta in un piccolo file locale:

{ "port": 3975 }
  • Accettate solo porte 1024–65535.
  • È ignorato da Git: non viene mai pubblicato né sincronizzato.
  • Viene adottato all'avvio solo se PORT non è impostata nell'ambiente.

Costanti interne utili

Costante Valore A cosa serve
Cleanup stanze vuote 60 s Una stanza senza host né listener viene eliminata dopo questo tempo
Grazia riconnessione host 8 s Dopo una caduta anomala dell'host la stanza resta recuperabile con la stessa chiave
Grazia riconnessione listener 5 s Un telefono che cambia rete/lock screen ha tempo di tornare senza perdere il posto
Heartbeat WebSocket 10 s Ping periodico; i client muti vengono terminati
Messaggio signaling max 24 KB Oltre: chiusura immediata 1009 "Message too large"
Buffer log server 400 righe Anello consultabile dal Control Center (/api/logs)
Testo QR max 2048 char Limite endpoint /qr

Livelli di log

Formato riga: [YYYY-MM-DD HH:MM:SS] [LIVELLO] [TAG] messaggio, colori ANSI quando l'output è un terminale. Ogni modulo usa tag propri (es. Server, Signaling) concatenabili con child. I livelli:

Livello Valore Uso tipico
DEBUG 0 Diagnostica approfondita (registrazioni, candidati ICE, decisioni ANAE)
INFO 1 Eventi normali: avvii, join/leave, stanze create
WARN 2 Rate limit superato, origin respinta, TLS fallito
ERROR 3 Errori runtime che richiedono attenzione
SILENT 4 Nessun output

Modalità HTTPS / WSS

# PowerShell
$env:WIFORA_TLS_CERT = "C:\certs\cert.pem"
$env:WIFORA_TLS_KEY  = "C:\certs\key.pem"
npm start
  • Entrambe le variabili sono obbligatorie; se una manca o il file non si legge, Wifora riparte in HTTP con un warning.
  • Tutti gli URL (QR inclusi) passano a https:///wss://; anche l'annuncio mDNS dichiara transport: https.
  • Quando ha senso: reti condivise/non fidate e per abilitare API che esigono contesto sicuro sui dispositivi (es. Screen Wake Lock su iOS via LAN HTTP non è disponibile — l'applo degrada elegantemente nascondendo il toggle).
  • Per test locali consigliamo certificati validi generati con mkcert: i self-signed generano avvisi nei browser dei telefoni.
