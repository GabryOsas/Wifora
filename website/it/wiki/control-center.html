Control Center Web

Una console nel browser per gestire il server Wifora senza toccare il terminale: avvio, stop, cambio porta, log live e QR di collegamento.

Come si avvia

npm run console
# oppure
node control-center.mjs --wifora-control --open
# oppure doppio clic su Controllo-Wifora.bat

Si apre http://localhost:3976. Il Control Center è un piccolo daemon separato che resta proprietario dell'eventuale processo di streaming.

Le sezioni dell'interfaccia

Stato server

  • Pill Attivo/Fermo.
  • Tre metriche: Porta configurata, Uptime ("Xh Ym"), Ascoltatori totali con elenco nomi dispositivo.
  • Link "Apri Host Page" quando il server gira.

Azioni server

Avvia, Ferma, Riavvia. Se provi ad avviare mentre è già attivo ricevi "already-running". Se la porta scelta è occupata da un altro processo, il daemon tenta il takeover: chiude i processi Wifora orfani e libera la porta prima di ripartire.

Collega il telefono

QR code 200×200 con l'URL di ascolto del PC (aggiornato alla rete attiva), campo URL copiabile con feedback "copiato".

Cambio porta

  • Input numerico valido 1024–65535; salvando, il valore persiste in wifora.config.json.
  • Se il server è attivo viene riavviato automaticamente sulla nuova porta (puoi disattivarlo col flag restart=false dall'API).
  • "Libera Porta & Ferma Processi" forza la chiusura di chi occupa la porta.

Schede di rete

Elenco adapter fisici con IP e URL di ascolto pronto; il primo è marcato "consigliata per iPhone". Gli adapter virtuali (VPN, Docker, Hyper-V, Tailscale…) vengono filtrati automaticamente.

API interne del daemon

Endpoint Metodo Descrizione
/api/status GET running, pid, uptime, porta, listeners, stanze, IP LAN, adapter
/api/logs?since=N GET Log incrementali con cursore (buffer circolare 400 righe)
/api/server/start POST Avvia lo streamer; 409 se già attivo; takeover porta occupata
/api/server/stop POST Stop grazioso (IPC) + sweep forzato; riporta portFree
/api/server/restart POST stop + start in una sola chiamata
/api/port POST {port} valida 1024–65535, salva config, riavvio opzionale
/api/port/free POST Libera forzatamente la porta indicata
/qr?text=… GET QR PNG identico a quello dello streamer

Sicurezza del daemon

  • In ascolto solo su 127.0.0.1: nessun altro dispositivo della rete può raggiungerlo.
  • Le mutazioni (POST) verificano l'intestazione Origin contro l'host (same-origin guard).
  • Body limitati a 4 KB; risposte API sempre no-store.

Come gestisce il processo streamer

  1. Spawn di node server.mjs --wifora-managed con IPC dedicato e PORT nell'ambiente.
  2. Attesa readiness sondando /api/stats ogni 250 ms (deadline 6 s).
  3. Allo stop: messaggio IPC wifora:shutdown → 2.5 s di grazia → taskkill forzato → verifica porta libera.
  4. La UI interroga /api/status ogni 2 secondi; se il daemon non risponde compare il banner "Console non raggiungibile".
