API HTTP

Tutte le route HTTP esposte dal server di streaming (porta 3975) e dal Control Center (3976). Ogni risposta include gli header di sicurezza descritti in Sicurezza.

Server di streaming :3975

Route Descrizione
GET / Redirect 302 intelligente: i device mobile vanno a listen.html, il resto a host.html (query string preservata)
GET /api/network IP LAN filtrati + porta → { "port": 3975, "addresses": ["192.168.1.50", …] } (no-store)
GET /api/capabilities Potenzialità del server: protocolVersion, transports, nativeCapture, discovery, nota su mDNS/browser
GET /api/stats Solo da localhost (altrimenti 403): stanze attive, listener per stanza, nomi, totale
POST /api/leave Uscita affidabile del listener al termine pagina; risponde sempre 204 anche con body invalido; header CORS *
GET /qr?text=… QR PNG 420 px (ECC M); 400 se testo assente o > 2048 char; no-store/private
WS /native-audio?room=…&key=… Upgrade WebSocket autenticato (room+hostKey+origin): relay PCM binario verso il solo tab host, backpressure 48 KiB
GET /*.statici File di public/: MIME whitelist, HTML no-cache, resto max-age 300; path traversal respinto con 403

Esempi rapidi

# Indirizzi LAN
curl http://localhost:3975/api/network

# Statistiche (solo dal PC stesso)
curl http://localhost:3975/api/stats
# { "rooms": [{ "roomId":"K7P2M9XA","hostConnected":true,
#               "listeners":1,"listenerNames":["iPhone di Mario"] }],
#   "totalListeners": 1 }

# Uscita affidabile del listener
curl -X POST http://localhost:3975/api/leave \
     -d '{"roomId":"K7P2M9XA","sessionId":"ls_abc123"}'

Control Center daemon :3976

Route Metodo Risposta / errori
/api/status GET running, owner(console/external/none), pid, uptimeSec, porta, reachable, listeners, rooms, lanAddresses, adapters
/api/logs?since=N GET {cursor, lines[]} — consumo incrementale
/api/server/start POST 200 ok · 409 already-running · takeover con tookOver:true se la porta era occupata · 500 exited/timeout
/api/server/stop POST {ok, wasRunning, portFree}
/api/server/restart POST stop + start
/api/port POST {port} valida 1024–65535 (400 invalid-port), salva config, riavvio se attivo e porta diversa
/api/port/free POST forza liberazione porta {portFree, port}
/qr?text=… GET QR PNG identico allo streamer
  • Le POST verificano l'Origin (richieste senza Origin — come curl — sono ammesse).
  • Body limitati a 4 KB; risposte JSON no-store.
  • Il daemon è raggiungibile solo da 127.0.0.1.
