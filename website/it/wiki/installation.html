Installazione

Tre comandi e sei online. Nessun servizio di sistema, nessun driver: Wifora vive interamente in una cartella.

Prerequisiti

  • PC host: Windows 10 o 11.
  • Browser host: Google Chrome o Microsoft Edge (aggiornati).
  • Node.js ≥ 18: scaricalo da nodejs.org (versione LTS). Verifica con node -v.
  • Git (opzionale, solo per il metodo clone).
  • Rete: PC e dispositivi sulla stessa LAN (Wi-Fi o Ethernet).

Metodo A — Git clone (consigliato)

git clone https://github.com/GabryOsas/Wifora.git
cd Wifora
npm install

Metodo B — Archivio ZIP

  1. Vai alla pagina Releases e scarica Source code (zip).
  2. Estrai la cartella dove preferisci (es. C:\Wifora). Il percorso può contenere spazi.
  3. Apri PowerShell/CMD in quella cartella ed esegui npm install.

Cosa installa npm

Pacchetto Ruolo
ws Server WebSocket per la segnalazione WebRTC e il relay audio nativo.
qrcode Generazione server-side dei QR code PNG (endpoint /qr).
bonjour-service Annuncio mDNS/Bonjour _wifora._tcp.local sulla rete.

Tre dipendenze runtime, zero binari nativi Node: installazione leggera e affidabile. ESLint e Prettier sono solo devDependencies.

Primo avvio

npm start

In alternativa:

  • npm run menu — menu interattivo nel terminale (guida CLI);
  • doppio clic su Avvia-Wifora.bat — verifica Node, esegue npm install al primo avvio e apre il menu;
  • doppio clic su Controllo-Wifora.bat — avvia direttamente la console web (Control Center).

Verifica del funzionamento

  1. Apri http://localhost:3975 sul PC: vieni reindirizzato automaticamente alla pagina host (su un telefono, allo stesso indirizzo verresti mandato alla pagina di ascolto).
  2. Nel terminale compaiono le righe Wifora ready at http://localhost:3975/host.html e l'URL LAN per gli smartphone.
  3. All'avvio Windows potrebbe chiedere il permesso al firewall per Node.js: consenti sulle reti private.

Aggiornamento

git pull
npm install   # solo se package.json è cambiato

Con il metodo ZIP: riscarica l'archivio nuovo e sostituisci i file (la tua configurazione locale wifora.config.json non è parte del repository).

Disinstallazione pulita

  1. Esegui Termina-Wifora.bat (o chiudi il terminale con Ctrl+C): ferma processi e libera le porte 3975/3976.
  2. Elimina la cartella del progetto. Fine.

Wifora non crea servizi Windows, attività pianificate né voci di registro. Tutto ciò che serve vive nella cartella; le impostazioni utente (tema, lingua) sono nel localStorage del browser.

Opzionale: helper WASAPI nativo

Per la massima robustezza di cattura puoi compilare wifora-audio.exe dai sorgenti C++ inclusi. Non è richiesto: il percorso browser funziona da solo. Vedi la pagina dedicata.
