CLI Menu & Windows Scripts

Wifora's terminal face: an interactive menu with a live dashboard, plus three .bat scripts for everyday no-command-line use.

Interactive menu

npm run menu
# or double-click Avvia-Wifora.bat

Navigate with ↑/↓ + Enter; q or Ctrl+C exits. Colorful ASCII banner included.

Item What it does
Start Wifora Server Ensures the Control daemon is alive, then starts the streamer on the chosen port. Shows addresses (localhost + LAN) and opens the live dashboard: logs and listeners refreshed every 1.2 s.
Dashboard shortcuts B reopens the host page in the browser · C opens the web Control Center · S stops the server and returns to the menu · Q stops everything and exits.
Open Web Control Center Opens http://localhost:3976 in your browser (guide).
Change Port Asks for a new port valid in 1024–65535, saves it to wifora.config.json and applies it if the server is running.
View Network Adapters Lists physical adapters with IPs; the first is marked "recommended for phones"; each row shows its direct listen.html link.
Stop Server & Free Port Graceful stop via daemon; fallback closes Wifora-marked processes and frees the port (with final verification).
Exit Program Stops the server and exits cleanly.

Direct mode: if the Control daemon doesn't respond, the menu manages the streamer itself (spawn marked --wifora-managed) so you're never stuck.

The three .bat files

Avvia-Wifora.bat — full launch

  1. Sets UTF-8 in the console (chcp 65001).
  2. Checks Node.js is installed; otherwise a clear message + link to nodejs.org.
  3. If node_modules is missing it automatically runs npm install.
  4. Launches the interactive menu.

Controllo-Wifora.bat — web console

Same environment checks, then starts the Control Center with automatic browser opening (control-center.mjs --wifora-control --open).

Termina-Wifora.bat — total stop

  1. Finds node.exe processes marked --wifora-managed / --wifora-control and force-terminates them.
  2. Frees ports 3975 and 3976 by closing any remaining owners.
  3. Re-verifies Listen state on both ports and prints [OK] Verified: ports 3975 and 3976 are free. or lists busy ones.

It's also the right tool for a clean uninstall or when an orphan instance holds a port hostage.
