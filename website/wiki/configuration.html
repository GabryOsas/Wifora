Environment Variables & Configuration

Every configuration lever: environment variables, the local file, internal constants and HTTPS mode.

Environment variables

Variable Default Description
PORT 3975 HTTP/WebSocket streaming server port.
WIFORA_MAX_LISTENERS 5 Max listeners per room. Out-of-range values are clamped to 1–32.
LOG_LEVEL INFO DEBUG | INFO | WARN | ERROR | SILENT or number 0–4. Invalid values fall back to INFO.
WIFORA_TLS_CERT — PEM certificate path (together with WIFORA_TLS_KEY enables HTTPS/WSS).
WIFORA_TLS_KEY — PEM private key path.
WIFORA_CONTROL_PORT 3976 Control Center daemon port (loopback only).
WIFORA_WASAPI_HELPER — Explicit path to wifora-audio.exe.

Examples

# PowerShell
$env:PORT = "8080"; $env:WIFORA_MAX_LISTENERS = "8"; npm start

# CMD
set PORT=8080 && set WIFORA_MAX_LISTENERS=8 && npm start

# bash / macOS / Linux
PORT=8080 LOG_LEVEL=DEBUG npm start

wifora.config.json

The CLI menu and Control Center share the chosen port in a small local file:

{ "port": 3975 }
  • Only ports 1024–65535 accepted.
  • It is git-ignored: never published or synced.
  • Adopted at startup only when PORT is not set in the environment.

Useful internal constants

Constant Value Purpose
Empty-room cleanup 60 s A room with no host and no listeners is removed after this time
Host reconnect grace 8 s After an abnormal host drop the room stays recoverable with the same key
Listener reconnect grace 5 s A phone switching networks/lock screens can return without losing its seat
WebSocket heartbeat 10 s Periodic ping; silent clients get terminated
Max signaling message 24 KB Beyond: immediate 1009 "Message too large"
Server log buffer 400 lines Ring buffer readable from the Control Center (/api/logs)
QR text limit 2048 chars /qr endpoint cap

Log levels

Line format: [YYYY-MM-DD HH:MM:SS] [LEVEL] [TAG] message, ANSI colors when output is a terminal. Every module uses its own tag (e.g. Server, Signaling) chainable via child. Levels:

Level Value Typical use
DEBUG 0 Deep diagnostics (registrations, ICE candidates, ANAE decisions)
INFO 1 Normal events: starts, join/leave, rooms created
WARN 2 Rate limits hit, rejected origins, TLS failures
ERROR 3 Runtime errors needing attention
SILENT 4 No output at all

HTTPS / WSS mode

# PowerShell
$env:WIFORA_TLS_CERT = "C:\certs\cert.pem"
$env:WIFORA_TLS_KEY  = "C:\certs\key.pem"
npm start
  • Both variables are required; if one is missing or unreadable Wifora falls back to HTTP with a warning.
  • All URLs (QR included) switch to https:///wss://; the mDNS announcement also declares transport: https.
  • When it makes sense: shared/untrusted networks, and to enable APIs requiring secure contexts on devices (e.g. Screen Wake Lock on iOS over plain LAN HTTP is unavailable — the app degrades gracefully by hiding the toggle).
  • For local tests we suggest valid certificates from mkcert: self-signed ones trigger browser warnings on phones.
