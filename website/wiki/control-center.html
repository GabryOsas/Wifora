Wifora/Wiki/Web Control Center

Web Control Center

A browser console to manage the Wifora server without touching the terminal: start, stop, port changes, live logs and pairing QR.

How to launch it

npm run console
# or
node control-center.mjs --wifora-control --open
# or double-click Controllo-Wifora.bat

It opens http://localhost:3976. The Control Center is a small separate daemon that owns the streaming process.

Interface sections

Server status

  • Pill showing Running/Stopped.
  • Three metrics: configured Port, Uptime ("Xh Ym"), total Listeners with the device-name list.
  • "Open Host Page" link whenever the server is running.

Server actions

Start, Stop, Restart. Starting while already active returns "already-running". If the chosen port is busy, the daemon attempts a takeover: it closes orphan Wifora processes and frees the port before starting.

Pair your phone

200×200 QR with the PC's listening URL (updated for the active network), plus a copyable URL field with "copied" feedback.

Port change

  • Number input valid in 1024–65535; saving persists the value into wifora.config.json.
  • If the server is running it restarts automatically on the new port (restart=false flag available via API).
  • "Free Port & Stop Processes" force-closes whoever occupies the port.

Network adapters

List of physical adapters with IPs and ready-made listening URLs; the first is marked as recommended for phones. Virtual adapters (VPN, Docker, Hyper-V, Tailscale…) are filtered automatically.

Daemon API

Endpoint Method Description
/api/status GET running, pid, uptime, port, listeners, rooms, LAN IPs, adapters
/api/logs?since=N GET Incremental logs with cursor (400-line ring buffer)
/api/server/start POST Starts the streamer; 409 if already running; takeover when the port is busy
/api/server/stop POST Graceful stop (IPC) + forced sweep; reports portFree
/api/server/restart POST stop + start in one call
/api/port POST {port} valid 1024–65535, saves config, optional restart
/api/port/free POST Force-frees the given port
/qr?text=… GET QR PNG identical to the streamer's

Daemon security

  • Binds to 127.0.0.1 only: no other network device can reach it.
  • Mutations (POST) verify the Origin header against the host (same-origin guard).
  • Bodies capped at 4 KB; API responses are always no-store.

How it manages the streamer process

  1. Spawns node server.mjs --wifora-managed with a dedicated IPC channel and PORT in its environment.
  2. Waits for readiness by polling /api/stats every 250 ms (6 s deadline).
  3. On stop: IPC message wifora:shutdown → 2.5 s grace → forced taskkill → port-free verification.
  4. The UI polls /api/status every 2 seconds; if the daemon is unreachable a "Console unreachable" banner appears.
