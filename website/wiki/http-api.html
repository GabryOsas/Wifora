HTTP API

Every HTTP route exposed by the streaming server (port 3975) and the Control Center (3976). All responses include the security headers described in Security.

Streaming server :3975

Route Description
GET / Smart 302 redirect: mobile devices go to listen.html, everything else to host.html (query string preserved)
GET /api/network Filtered LAN IPs + port → { "port": 3975, "addresses": ["192.168.1.50", …] } (no-store)
GET /api/capabilities Server capabilities: protocolVersion, transports, nativeCapture, discovery, mDNS/browser note
GET /api/stats Localhost only (otherwise 403): active rooms, listeners per room, names, total
POST /api/leave Reliable listener exit on page unload; always answers 204 even with invalid body; CORS header *
GET /qr?text=… QR PNG 420 px (ECC M); 400 on missing text or > 2048 chars; no-store/private
WS /native-audio?room=…&key=… Authenticated WebSocket upgrade (room+hostKey+origin): binary PCM relay toward the host tab only, 48 KiB backpressure
GET /*static Files from public/: MIME whitelist, HTML no-cache, rest max-age 300; path traversal rejected with 403

Quick examples

# LAN addresses
curl http://localhost:3975/api/network

# Statistics (from the PC itself only)
curl http://localhost:3975/api/stats
# { "rooms": [{ "roomId":"K7P2M9XA","hostConnected":true,
#               "listeners":1,"listenerNames":["Mario's iPhone"] }],
#   "totalListeners": 1 }

# Reliable listener exit
curl -X POST http://localhost:3975/api/leave \
     -d '{"roomId":"K7P2M9XA","sessionId":"ls_abc123"}'

Control Center daemon :3976

Route Method Response / errors
/api/status GET running, owner(console/external/none), pid, uptimeSec, port, reachable, listeners, rooms, lanAddresses, adapters
/api/logs?since=N GET {cursor, lines[]} — incremental consumption
/api/server/start POST 200 ok · 409 already-running · takeover with tookOver:true when the port was busy · 500 exited/timeout
/api/server/stop POST {ok, wasRunning, portFree}
/api/server/restart POST stop + start
/api/port POST {port} valid 1024–65535 (400 invalid-port), saves config, restarts if running and port changed
/api/port/free POST force-frees the port {portFree, port}
/qr?text=… GET QR PNG identical to the streamer's
  • POSTs verify Origin (requests without Origin — like curl — are allowed).
  • Bodies capped at 4 KB; JSON responses are no-store.
  • The daemon listens on 127.0.0.1 only.
