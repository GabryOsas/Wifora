Installation

Three commands and you're live. No system services, no drivers: Wifora lives entirely inside one folder.

Prerequisites

  • Host PC: Windows 10 or 11.
  • Host browser: Google Chrome or Microsoft Edge (up to date).
  • Node.js ≥ 18: get it at nodejs.org (LTS). Verify with node -v.
  • Git (optional, only for the clone method).
  • Network: PC and devices on the same LAN (Wi-Fi or Ethernet).

Method A — Git clone (recommended)

git clone https://github.com/GabryOsas/Wifora.git
cd Wifora
npm install

Method B — ZIP archive

  1. Open the Releases page and download Source code (zip).
  2. Extract the folder wherever you like (e.g. C:\Wifora). Spaces in the path are fine.
  3. Open PowerShell/CMD there and run npm install.

What npm installs

Package Purpose
ws WebSocket server for WebRTC signaling and the native audio relay.
qrcode Server-side QR PNG generation (/qr endpoint).
bonjour-service mDNS/Bonjour advertisement as _wifora._tcp.local.

Three runtime dependencies, zero native Node binaries: a light, reliable install. ESLint and Prettier are devDependencies only.

First run

npm start

Alternatives:

  • npm run menu — interactive terminal menu (CLI guide);
  • double-click Avvia-Wifora.bat — checks Node, runs npm install on first use, opens the menu;
  • double-click Controllo-Wifora.bat — starts straight into the web console (Control Center).

Verify it works

  1. Open http://localhost:3975 on the PC: you are redirected to the host page (on a phone, the same address lands on the listening page).
  2. The terminal prints Wifora ready at http://localhost:3975/host.html plus the LAN URL for smartphones.
  3. On first start Windows may ask firewall permission for Node.js: allow it on private networks.

Updating

git pull
npm install   # only if package.json changed

ZIP method: download the new archive and replace the files (your local wifora.config.json is not part of the repository).

Clean uninstall

  1. Run Termina-Wifora.bat (or close the terminal with Ctrl+C): processes stop, ports 3975/3976 are freed.
  2. Delete the project folder. Done.

Wifora creates no Windows services, scheduled tasks or registry entries. Everything lives in the folder; user preferences (theme, language) are stored in your browser's localStorage.

Optional: native WASAPI helper

For maximum capture robustness you can compile wifora-audio.exe from the bundled C++ sources. It is not required: the browser path works on its own. See the dedicated page.
