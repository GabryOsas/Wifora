Listener Guide — Receiving Audio

How to join from iPhone, iPad, Android or a second PC — and how to get the most out of every control on the listening page.

Three ways to connect

  1. QR code (recommended): scan with your phone. It already contains room and token.
  2. Direct link: open the URL shown by the host, in the form http://IP:3975/listen.html?room=CODE&token=….
  3. Manual entry: go to http://PC-IP:3975/listen.html and type the 8-character code. If the room is token-protected you also need the token from the link (the code alone suffices only when the host generated no token).

The token stops anyone who merely knows the room code (8 characters) from listening silently: without a valid token the join is refused with "Invalid or missing listener token." See Security.

The playback screen

  • Status pill: Connected / Waiting / Weak signal / Disconnected, refreshed every second with telemetry.
  • Local volume: adjusts only your headphones. The curve is perceptual (v²) so mid-range feels natural.
  • VU meter: instantaneous level of the received stream (dedicated FFT-64 analyser).
  • Wake Lock: on-by-default toggle asking the system to keep the screen awake while listening (where the API exists).
  • Screen lock / app switch: audio resumes automatically when you return; if the browser blocks autoplay a "Tap to enable audio" box appears.

Connection & network details (HUD)

The "Connection & Network Details" accordion shows three live measures:

Indicator How to read it
Signal "Great Wi-Fi" / "Good" / "Unstable": bad when RTT > 100 ms or loss > 3%, warn above RTT 70 ms or 1.2% loss (with 2-sample anti-flapping)
Latency Current RTT to the host in milliseconds
Loss Packet-loss percentage detected by WebRTC

On the host panel your device row also shows Buffer (current jitter target), Sync (± estimated clock offset) and the active ANAE tier bitrate.

Media controls

The lock screen and system quick controls show "Wifora — Live Audio" with artwork and integrated play/pause (MediaSession API).

Install as an app (PWA)

  • Android: Chrome offers the "Add to Home screen" banner, or menu → Install app.
  • iOS: Safari → Share → "Add to Home Screen". The app opens full-screen with no browser bar.

The PWA pre-caches the shell (page, styles, logo) and works offline as an interface: of course audio only flows while the host is broadcasting on your network.

Connection reliability

  • Keep-alive: ping every 6 s; automatic reconnect with exponential backoff (500 ms → 5 s, max 6 attempts).
  • Peer recovery: if after 8 s the media connection isn't back, the client voluntarily recycles its socket (close 4010) for a clean restart.
  • Clean exit: the exit button notifies the host instantly (no timeout wait); even closing the tab sends a reliable notification (sendBeacon).
  • Kick: if the host removes you, you see "You have been disconnected by the PC host." and cannot rejoin that room.
