Quick Start — your first broadcast in 60 seconds

The shortest path from zero to audio in your phone's headphones.

The steps

1 · Start the server

cd Wifora
npm start

(or double-click Avvia-Wifora.bat). The terminal prints the LAN address to use from your phone.

2 · Open the host page

In Chrome or Edge on the PC go to http://localhost:3975, then hit the big blue button.

3 · Share system audio

The browser share picker opens:

  • pick the Entire Screen tab;
  • tick "Share system audio" — essential;
  • confirm with Share.

The screen video track is stopped immediately: Wifora keeps only the audio track so all bandwidth goes to sound.

4 · Connect your phone

The screen now shows the QR code and the 8-character room code:

  • iPhone: open the Camera app, point at the QR, tap the link that appears.
  • Android: scan with Camera or Google Lens, or open Chrome and type the URL http://PC-IP:3975/listen.html then enter the code.

5 · Listen

The phone joins the room and audio starts in well under a tenth of a second. The host device list shows your phone appear with live telemetry (ping, bitrate, loss).

6 · Stop everything

  • On the PC: Stop Broadcast → all listeners receive the room-ended event.
  • On the phone: the exit button (or close the tab) → the host sees the device leave.

What to expect

  • Perceived latency: imperceptible for movies/series (35–65 ms typical on 5 GHz).
  • Quality: self-adjusting (ANAE). On clean Wi-Fi you'll already be at 256 kbps "Studio Master".
  • Multiple devices: more phones can join with the same QR/code up to the configured limit (default 5).

If something doesn't work

  • No sound? Almost always the missing "Share system audio" checkbox, or the phone's autoplay block (tap the screen).
  • Code rejected? That broadcast already ended: regenerate the QR.
  • Everything else: Troubleshooting.
