Security Model & Privacy

Wifora is built to stay inside your network: here is every implemented security control — and the remaining limits, honestly declared.

Three separated layers

MEDIA      Mandatory WebRTC DTLS-SRTP, direct P2P on the LAN
           iceServers: [] → no packets toward STUN/TURN/cloud
SIGNALING  Local HTTP/WebSocket (optional HTTPS/WSS)
           Origin allow-list + rate limiting + payload cap
ADMIN      Control Center on 127.0.0.1 only, same-origin guard
           /api/stats loopback only

Room authentication

  • hostKey: 32 random bytes (43 base64url chars = 256 bits). Verified with crypto.timingSafeEqual: no timing attack can guess it.
  • listenerToken: 16 bytes (128 bits) embedded in the QR/link. Without a valid token, knowing the room code is not enough to join.
  • Room code: ~40 bits of entropy (charset 32^8). Alone it doesn't grant entry when a token exists; and brute force gets throttled by rate limiting.
  • Authenticated replacement: a host re-entering with the same key takes over the old socket ("Host reconnected"); anyone without the key only ever sees "This room is already in use."

Rate limiting (per IP)

Limit Window Max Action
WebSocket upgrade 10 s 30 socket destroyed
Non-existent room codes 30 s 8 close 1008
Failed auths (key/token) 30 s 10 close 1008
Message payload 24 KB close 1009
Listeners per room default 5 (max 32) refused with a clear message

HTTP hardening

Content-Security-Policy: default-src 'self'; connect-src 'self' ws: wss:;
  img-src 'self' data:; media-src 'self' blob:; script-src 'self';
  style-src 'self'; base-uri 'self'; form-action 'self'
Cross-Origin-Resource-Policy: same-origin · Referrer-Policy: no-referrer
X-Content-Type-Options: nosniff · X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
  • No inline scripts or styles: the CSP stays strict, and tests enforce it.
  • Path traversal blocked twice: filter on ../%2e%2e plus final verification that the normalized path stays inside public/.
  • WebSocket origin verified against localhost + active LAN IPs on the exact port: malicious external pages cannot open signaling (CSWSH rejected).
  • MIME whitelist: no arbitrary files served from disk.

Privacy by design

  • Zero telemetry, zero analytics, zero beacons. No calls leave your LAN — not even update checks.
  • Logs never contain hostKey, listenerToken, SDP dumps or ICE credentials.
  • Device telemetry stays in memory for the session duration only.
  • Minimal runtime dependencies (3) with weekly CI audit (npm audit --audit-level=high).

Known limits (transparency)

  • Over plain HTTP, signaling travels unencrypted on your LAN: media stays DTLS-SRTP encrypted regardless. On shared networks use TLS mode.
  • Anyone with physical network access and the full link (token included) can listen: that's the usage model (like handing someone your house keys).
  • No accounts or granular permissions: security relies on per-room secrets + a trusted network.
